ThemePicker は、利用者がアプリの配色を **ライト・ダーク・システム** から選ぶための部品です。
中身は [Picker](/components/picker/) で、選択は `localStorage` に保持し、`html[data-theme]` に反映します。

## プレビュー

<ThemePickerPreview />

このサイトのプレビューで選ぶと、Starlight も同じ `html[data-theme]` を読むため、サイト全体の配色が変わります。
Starlight 自身の切り替えの表示とはずれます。

## 使い方

`<head>` に `themeScript` を inline で置き、ページ内に `ThemePicker` を置きます。

```vue
<!-- Vue（Vike の +Head.vue） -->
<script setup lang="ts">
import { themeScript } from '@koyori-app/ui-vue';
</script>

<template>
  <component :is="'script'" v-html="themeScript" />
</template>
```

```tsx
// React
import { themeScript } from '@koyori-app/ui-react';

<script dangerouslySetInnerHTML={{ __html: themeScript }} />
```

```vue
<ThemePicker label="テーマ" />
```

- `html[data-theme]` は常に `light` か `dark` の 2 値です。「システム」は OS の配色を調べて、この 2 値のどちらかにします。
- 選択は `localStorage` の `koyori-theme` に `light` / `dark` で保持します。「システム」は保持を消した状態です。
- `themeScript` は最初の描画より前に `data-theme` を決め、OS の配色が変わったときも付け直します。
  置かないと、再読み込みのたびに既定のダークで描いてから切り替わり、保持も OS の変化も当たりません。
- CSP で inline script を禁じているアプリは、`<script>` に nonce を付けてください。
- ページの地は利用側が `--koyori-color-surface` で塗ります。部品は地の色を塗りません。
- 別のタブでの変更は、そのタブを再読み込みするまで反映されません。

## Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `label` | `string` | 必須 | 読み上げ名。トリガーは「テーマ: ライト」のように読まれる |

## 関数

| 名前 | 説明 |
| --- | --- |
| `themeScript` | `<head>` に inline で置くスクリプトの文字列 |
| `setTheme(theme)` | `'light'` / `'dark'` / `'system'` を保持し、`html[data-theme]` に反映する。Dropdown の項目など、別の形で切り替えを出すときに使う |
| `storedTheme()` | 保持している選択。無い・読めない・知らない値は `'system'` |

サーバー描画では保持した選択を知らないため、マウントされるまでトリガーは「システム」と表示されます。
配色そのものは `themeScript` が最初から正しく当てます。

## アクセシビリティ

操作とキーボードは [Picker](/components/picker/) と同じです。トリガーの読み上げ名は「テーマ: ライト」のように、`label` と選択中の項目になります。
選択中の項目をもう一度選んでも、選択なしにはなりません。
