Alert は、送信の失敗や取得の失敗など、入力欄ひとつに収まらないメッセージをセクションの先頭に置きます。
入力欄ごとのエラーは [Field](/components/field/) の `error` を使ってください。
表示・非表示・再試行の処理はアプリ側で持ちます。

## プレビュー

「送信」を押すと失敗の Alert が出ます。「再試行」で成功の Alert に入れ替わり、「閉じる」で送信ボタンへフォーカスが戻ります。

<AlertPreview />

## 使い方

`message` と `variant` を渡し、必要なら `onRetry`・`onDismiss` を足します。渡したときだけボタンが出ます。

```tsx
// React
{status === 'error' && <Alert message="ネットワークに接続できず、送信できませんでした。"
  onRetry={() => submit()} onDismiss={dismiss} />}
```

```vue
<!-- Vue -->
<Alert v-if="status === 'error'" message="ネットワークに接続できず、送信できませんでした。"
  :on-retry="submit" :on-dismiss="dismiss" />
```

## Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `message` | `string` | 必須 | 本文。何が起きたかと次にできることを書く |
| `variant` | `'danger' \| 'warning' \| 'info' \| 'success'` | `'danger'` | 種類。色・枠線・接頭辞・`role` が変わる |
| `prefix` | `string` | `エラー` / `注意` / `お知らせ` / `完了` | 本文の前に表示・読み上げする言葉。空文字・空白だけなら既定に戻る |
| `onRetry` | `() => void` | — | 再試行ボタンを表示し、押下を通知する |
| `retryLabel` | `string` | `'再試行'` | 再試行ボタンの文言 |
| `onDismiss` | `() => void` | — | 閉じるボタンを表示し、押下を通知する |
| `dismissLabel` | `string` | `'閉じる'` | 閉じるボタンの読み上げ名 |

Alert は自分では消えません。`onDismiss` を受けてアプリ側が表示をやめます。
再試行の API 呼び出し、成否の判定、状態の更新も利用側の責務です。

## アクセシビリティ

- `danger`・`warning` は `role="alert"`、`info`・`success` は `role="status"` です。
  失敗と注意は進行中の読み上げに割り込み、案内と完了は読み終わるのを待ちます。
- `role` は要素が現れた時点から付いているため、後から表示された Alert も読み上げられます。
  そのため、表示のたびに `key` を変えて作り直さないでください。作り直すと通知が二重になったり、逆に読まれなくなったりします。
- ライブ領域には接頭辞と本文だけを入れ、再試行・閉じるボタンは外に置いています。
  ボタンの出入りが読み上げに混ざりません。本文を差し替えると、`aria-atomic="true"` により接頭辞と本文が 1 回で読まれます。
- 同じ内容を Field の `error` や別の `aria-live` 領域と同時に出さないでください。二重に通知されます。
- 種類は色だけでなく接頭辞の言葉でも伝えます。接頭辞は消せません。強制配色では接頭辞が本文と同じ色になり、言葉だけが残ります。
- 閉じたあとのフォーカス先は利用側が決めます。閉じるボタンは消えるため、操作の起点（送信ボタンなど）へ戻してください。
- Tab の順は 再試行 → 閉じる です。アニメーションを持たないため、「動きを減らす」設定で変わる動きはありません。

## スタイル

- 種類ごとの色は共通トークンです。文字・枠線は `--koyori-color-danger` / `-warning` / `-info` / `-success`、
  背景は同名の `-subtle` を使います。接頭辞の色と本文の `--koyori-color-text` は、
  それぞれの `-subtle` 背景に対してコントラスト比 4.5:1 以上、枠線は 3:1 以上を保っています。
- 個別に変える場合は、Alert を囲む要素か Alert 自身で `--alert-color`（文字・枠線）と `--alert-background`（背景）を上書きします。
  上書きするときも上のコントラスト比を保ってください。
- 文字サイズ・余白・角丸は共通トークンに従います。本文の上下の余白はボタンの高さ（`--koyori-control-height-sm`）に合わせて計算するため、
  トークンを変えても 1 行目とボタンの高さが揃います。
- 再試行ボタンは Button の `tertiary`、閉じるボタンはアイコンだけの `ghost` です。
