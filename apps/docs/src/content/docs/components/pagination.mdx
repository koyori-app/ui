Pagination は、一覧の下に「1–20 / 120 件」のような範囲と、`‹ 前へ 1 2 3 4 5 6 7 … 32 次へ ›` のようなページ送りを並べます。
ページが多いときは先頭・末尾と現在ページの前後だけを出し、間を省略記号「…」にまとめます。
ページ単位で行き来する一覧に使います。下に読み足していく「さらに読み込む」方式は [DataList](/components/data-list/) の `hasMore` を使ってください。
現在のページ、URL との同期、データの取得は利用側で持ちます。

## プレビュー

47 件を 10 件ずつ表示します。番号や「次へ」を押すと一覧と範囲の文が切り替わり、フォーカスは押したボタンに残ります。

## 使い方

`page`（1 始まり）・`pageSize`・`total` を渡し、`onPageChange` で移りたいページを受け取ります。

```tsx
// React
<Pagination page={page} pageSize={20} total={total} onPageChange={setPage} loading={isFetching} />

// 総件数が分からない（カーソル式）とき
<Pagination page={page} pageSize={20} hasNext={!!nextCursor} onPageChange={setPage} />
```

```vue
<!-- Vue -->
<Pagination :page="page" :page-size="20" :total="total" :on-page-change="(next) => (page = next)" :loading="isFetching" />

<!-- 総件数が分からない（カーソル式）とき -->
<Pagination :page="page" :page-size="20" :has-next="!!nextCursor" :on-page-change="(next) => (page = next)" />
```

## Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `page` | `number` | 必須 | 1 始まりの現在ページ。制御のみ |
| `pageSize` | `number` | 必須 | 1 ページの件数。非有限・1 未満は 1 |
| `total` | `number` | — | 総件数。未取得なら省略する（範囲とページ番号は出さず、次へは `hasNext` に従う）。非有限は 0 件 |
| `hasNext` | `boolean` | `false` | `total` が無いときに次のページがあるか |
| `onPageChange` | `(page: number) => void` | — | 前へ・次へ・ページ番号で移りたいページを通知する |
| `siblingCount` | `number` | `2` | 現在ページの前後に出すページ数。狭い場所では `1` や `0` にする。非有限・負は 2 |
| `label` | `string` | `'ページ送り'` | `nav` の `aria-label` |
| `previousLabel` | `string` | `'前へ'` | 前へボタンの文言 |
| `nextLabel` | `string` | `'次へ'` | 次へボタンの文言 |
| `pageLabel` | `(page: number) => string` | `` `${page} ページ目` `` | ページ番号のボタンの名前。見えている数字を含める |
| `formatRange` | `(range: { from, to, total }) => string` | `` `${from}–${to} / ${total} 件` `` | 範囲の文。既定では 0 件のとき `'0 件'` |
| `hideRange` | `boolean` | `false` | 範囲の文を出さない |
| `loading` | `boolean` | `false` | 取得中。ボタンは残して `aria-disabled` にし、範囲に `aria-busy` を付ける |

`total` を超えたページを渡すと、末尾のページとして範囲を表示します。ページを直すかどうかは利用側が決めるため、
Pagination から `onPageChange` を呼ぶことはありません（前へ・次へは表示中のページを基準に動きます）。

## ページ番号の並び

先頭と末尾の 1 ページ、現在ページの前後 `siblingCount` ページを出し、間を「…」にまとめます。
「…」が 1 ページしか隠さないときはそのページを出すので、項目数は `2 × siblingCount + 5`（既定 9）に揃い、ページを移っても並びの幅がぶれにくくなります。

| 現在ページ（全 32 ページ） | 並び |
| --- | --- |
| 1〜5 | `1 2 3 4 5 6 7 … 32` |
| 6 | `1 … 4 5 6 7 8 … 32` |
| 28〜32 | `1 … 26 27 28 29 30 31 32` |

総件数が分からない（カーソル式）ときと 0 件のときは、ページ番号を出さず前へ・次へだけを並べます。

## キーボード操作

| キー | 動作 |
| --- | --- |
| Tab | 前へ → ページ番号 → 次へ の順に移動する。端でも前へ・次へに到達できる |
| Enter / Space | 前へ・次へはその向きへ、番号はそのページへ移す。端・現在ページ・取得中は何もしない |

## アクセシビリティ

- 全体は `nav` のランドマークで、名前は `label`（既定 `ページ送り`）です。一覧ごとに置く場合は「タスクのページ送り」のように区別できる名前にしてください。
- ページ番号は `role="list"` を付けた `ul` に並べます。番号のボタンの名前は「5 ページ目」のようにし、現在ページには `aria-current="page"` を付けます。
  現在ページも `button` のまま残すので、番号を押して現在ページになってもフォーカスは消えません。
- 省略記号「…」は `aria-hidden` で読み上げから外します。末尾のページ番号で全体のページ数は伝わります。
- 端のボタンや取得中のボタンは `disabled` ではなく `aria-disabled="true"` にし、押下を無視します。
  `disabled` にすると、押した直後にフォーカスが消えてページの先頭に戻ってしまうためです（DataList の「さらに読み込む」と同じ扱いです）。
- 範囲の文は `aria-live="polite"`・`aria-atomic="true"` のライブ領域です。ページを変えた直後もフォーカスはボタンに残るので、
  新しい範囲が読まれて操作の結果が分かります。同じ内容を別の `aria-live` 領域や `role="status"` で出さないでください。二重に通知されます。
- 取得中は範囲に `aria-busy="true"` を付け、取得が終わって範囲が変わってから読ませます。
- 総件数が分からないときは範囲を出しません。その場合はページの移動を一覧の見出しなど別の手段でも伝えてください。

## スタイル

- 前へ・次へは枠を持たないテキストのボタンで、`--koyori-color-selection-indicator` の文字とシェブロンです。
- ページ番号は `--koyori-color-text-secondary`、現在ページは `--koyori-color-accent` の面に `--koyori-color-on-accent` の太字です。色だけに頼らないよう太字も付けています。
  アクセントの色はテーマの `--koyori-color-accent` を上書きすると変わります。
- ホバーの背景は Tabs・Sidebar と同じく、一つの面が項目間を移ります（`shared/highlight` を再利用）。`aria-disabled` の上では出しません。
- `aria-disabled` のときは `--koyori-color-text-disabled` の文字になり、取得中の現在ページは無効の面になります。
- 範囲の文は `--koyori-color-text-secondary` で、数字は等幅（`tabular-nums`）にしてページを変えても幅がぶれにくくしています。
- 範囲の文は左、ページ送りは右に置きます。`hideRange` のときはページ送りを中央に置きます。狭い幅では折り返します。
- 強制配色では現在ページを `Highlight` の枠で示し、`aria-disabled` のボタンを `GrayText` にします。
