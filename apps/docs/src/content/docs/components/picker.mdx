単一・複数の項目を選ぶコンポーネントです。検索欄は `searchable={false}`（Vue: `:searchable="false"`）で省略できます。
選んだ項目のラベルは自動でトリガーとアクセシブルネームに反映されます。`label` には選ぶ対象の名前を渡してください。
コピーなどの操作実行には [Dropdown](../dropdown/) を使います。

## プレビュー

「担当チーム」は単一選択、「共有チーム」は複数選択です。`end` や `ﾃﾞｻﾞｲﾝ` で絞り込めます。

## 選択と検索

既定の単一選択は項目を選ぶと閉じます。`selectionMode="multiple"` は選択・解除しても開いたままです。
検索で見えなくなった項目の選択状態も保持します。開き直すと検索文字列をクリアします。
検索はラベルの部分一致で、大文字・小文字と全角・半角の違いを吸収します。
候補と空表示はすぐ更新し、件数の読み上げは入力が300ms止まってからまとめて通知します。閉じると保留中の通知を取り消します。

`selectedValues` と `onSelectionChange` でアプリ側から選択を管理できます。
省略した場合は内部で管理し、`defaultSelectedValues` を初期値に使います。
存在しない値は表示から除き、単一選択に複数の値を渡すと項目順で先頭の1件を使います。
単一選択を解除するときは、外側から `selectedValues` に空配列を渡してください。

## 非同期の候補取得

`loading`・`error`（取得失敗のメッセージ）・`onRetry` を渡すと、読み込みと再試行を表示できます。
API 呼び出し、エラーの判定、再試行中の状態更新は利用側で行います。Picker はコールバックの完了を待ちません。

```tsx
// React: reload は利用側で loading・error・items を更新する関数
<Picker label="担当者" items={members} selectionMode="multiple"
  selectedValues={values} onSelectionChange={setValues}
  loading={loading} error={error} onRetry={reload}
  emptyMessage="担当者に指定できる利用者がいません"
  noResultsMessage="一致するメンバーがいません" />
```

```vue
<!-- Vue -->
<Picker label="担当者" :items="members" selection-mode="multiple"
  :selected-values="values" :on-selection-change="setValues"
  :loading="loading" :error="error" :on-retry="reload"
  empty-message="担当者に指定できる利用者がいません"
  no-results-message="一致するメンバーがいません" />
```

表示と読み上げは「読み込み中 → 取得失敗 → 空候補／検索結果なし → 候補数」の順で優先します。
`items` が空なら「項目がありません」、候補はあるが検索に一致しない場合は「該当する項目がありません」と表示します。
`emptyMessage` は両方の既存の共通上書きです。検索結果なしだけを変えるときは `noResultsMessage` を指定します。
読み込み中・失敗時も、渡された候補は選択できます。再取得中も `items` を保持すると、選択中の名前と候補が引き続き表示されます。
`items` を一時的に空にしても選択値は書き換えず、候補が戻ると再び選択表示します。
候補にない値の選択を更新時にも保持する必要がある場合は、利用側で `selectedValues` を管理してください。

再試行ボタンは一覧の外に置き、`Tab` で移動して `Enter`・`Space` で実行できます。
実行前に検索欄へフォーカスを戻し、検索文字列・選択・アクティブな候補を保持します。
検索なしの場合は有効な候補がある一覧へ、なければトリガーへ戻します。後から取得が完了してもフォーカスを奪いません。
`onRetry` がなければメッセージだけを表示し、読み込み中は再試行ボタンを表示しません。
状態は既存の `role="status"` で300ms後に通知し、取得中の一覧には `aria-busy` を付けます。

## Props

| 名前 | 型 | 既定値・説明 |
| --- | --- | --- |
| `label` | `string` | 必須。選ぶ対象の名前と未選択時の表示 |
| `items` | `PickerItem[]` | 必須。`{ value: string, label: string, disabled?: boolean, src?: string }[]`。`value` は一意にする |
| `avatars` | `boolean` | `false`。選択肢の先頭に 24px のアバターを表示する。`src` がなければイニシャル |
| `selectionMode` | `'single' \| 'multiple'` | `single` |
| `searchable` | `boolean` | `true`。`false` なら検索欄を表示せず全候補から選ぶ |
| `selectedValues` | `string[]` | 外側で管理する選択値 |
| `defaultSelectedValues` | `string[]` | `[]`。内部で管理するときの初期値 |
| `onSelectionChange` | `(values: string[]) => void` | 選択時のコールバック |
| `searchPlaceholder` | `string` | `検索…` |
| `searchLabel` | `string` | 「label を検索」に相当する検索欄の名前 |
| `formatResultsCount` | `(count: number) => string` | 候補数の通知文。既定は「N件の候補」 |
| `selectionSeparator` | `string` | 複数のラベルの区切り。既定は `、` |
| `emptyMessage` | `string` | 候補0件の表示。未指定なら「項目がありません」。`noResultsMessage` 未指定時は検索結果なしにも使用 |
| `noResultsMessage` | `string` | 候補はあるが検索一致0件の表示。`emptyMessage`、次に「該当する項目がありません」へフォールバック |
| `loading` | `boolean` | `false`。候補の読み込み中。既存の候補は操作可能 |
| `loadingMessage` | `string` | `読み込み中…` |
| `error` | `string` | 候補の取得失敗メッセージ。空文字・未指定なら失敗表示なし。`loading` が優先 |
| `onRetry` | `() => void` | 取得失敗時の再試行。利用側で取得と状態更新を行う |
| `retryLabel` | `string` | `再試行` |
| `disabled` | `boolean` | `false`。全体を無効化する |
| `defaultOpen` | `boolean` | `false`。初期表示で開く |
| `icon` | React の要素、または `null` | 下矢印。`null` で非表示。Vue の差し替えは `#icon` スロット |
| `trigger` | React の要素 | トリガーに表示する内容。既定は選択中のラベル。Vue は `#trigger` スロット |

Vue では `:selected-values="values"`・`:on-selection-change="handler"` のように渡します。

## トリガーの表示を差し替える

`trigger` を渡すと、トリガーに出る選択中のラベルを別の表示に置き換えられます。
開閉・キーボード操作・`aria-expanded` はそのままで、読み上げ名も `label` と選択中のラベルから作ります。

```tsx
// React: 選択中の人をアバターで表示する
<Picker label="担当者" items={items} selectionMode="multiple"
  selectedValues={values} onSelectionChange={setValues}
  trigger={<AvatarGroup label="選択中の担当者" items={selected} max={3} size={24} />} />
```

```vue
<!-- Vue -->
<Picker label="担当者" :items="items" selection-mode="multiple"
  :selected-values="values" :on-selection-change="handler">
  <template #trigger>
    <AvatarGroup label="選択中の担当者" :items="selected" :max="3" :size="24" />
  </template>
</Picker>
```

中身はトリガーの `button` に入るため、`div` などは置けません。文字・`span`・画像を使ってください。
AvatarGroup のルートは `span` なので、そのまま置けます。
組み合わせた例は [担当者の選択](../../blocks/assignees/) にあります。

## Field との連携

Field 内ではトリガーを Input と同じ枠線・背景・エラー色にし、幅も Field に揃えます。
説明とエラーはトリガーにだけ関連付け、検索欄・一覧への移動で同じ説明を繰り返しません。
Field の `id` はトリガー、`required` は一覧の `aria-required` に使います。
必須の場合はトリガーの名前にも Field の `requiredText` を含め、閉じた状態で必須と分かるようにします。
必須チェックやフォーム送信する値はアプリ側で管理し、エラーを Field の `error` に渡してください。
選択結果は `onSelectionChange` で受け取ります。

## キーボード操作

| 場所・キー | 動作 |
| --- | --- |
| トリガーで `Enter` / `Space` / `↓` / `↑` | 開いて検索欄へ移動。検索なしは選択済みの候補（なければ先頭の有効な候補）、`↑` は最後へ |
| 検索欄で文字入力 | 一覧を絞り込む。日本語入力の変換確定では選択しない |
| 検索欄で `↓` / `↑` | 候補へ移動。`↑` は最後の候補へ |
| 一覧で `↓` / `↑` / `Home` / `End` | 無効な候補を飛ばして移動 |
| `Enter` | 対象の候補を選択。検索欄では選択済みの候補、なければ先頭の有効な候補 |
| 一覧で `Space` | 選択・解除。検索欄では空白を入力 |
| 一覧で先頭文字を入力 | その文字で始まる有効な候補へ移動 |
| `Tab` / `Shift + Tab` | 検索欄と一覧を移動。外に出ると閉じる |
| 再試行ボタンで `Enter` / `Space` | `onRetry` を呼ぶ。検索欄か一覧、候補がなければトリガーへ戻る |
| `Escape` | 閉じてトリガーに戻る |

検索欄と、単一・複数選択に対応したラベル付きの `listbox` を組み合わせています。
検索なしで有効な候補がない場合は、トリガーにフォーカスを残します。
候補の操作は [W3C の Listbox パターン](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/) を参考にしています。
外側クリックでも閉じ、動きを減らす設定ではアニメーションを停止します。

## 配置とスタイル

候補一覧は Vue では computed として共有し、React では参照ごとに再計算します。
各計算は件数に比例する処理です。1,001 件の検索・選択を検証しています。
全候補を DOM に置くため、数万件はアプリ側で検索・分割してください。

`--koyori-menu-width`（200px）と `--koyori-menu-max-height`（360px）で寸法を調整できます。
最大高・`--koyori-menu-gap`・`--koyori-menu-viewport-margin` は `px` に加え、`rem`・`calc()` でも指定できます。
これらの長さは開くときに計測し、開いている間は再利用します。変更は次に開いたときに反映します。
幅は Dropdown と同じ 200px で、トリガーや親要素の幅に影響されません。
狭い画面では縮小し、下に余白が足りないときは上に開きます。長い一覧では検索欄を残して候補だけをスクロールします。
親の `overflow: hidden` 等による切り取りは回避しません。
共通トークンと `--dropdown-hover-background`・`--dropdown-selected-background` を参照します。
パネル・項目・ハイライトは Dropdown とともに `shared/menu.module.css` を参照し、配置とハイライト座標の計算も共有します。

Vue 版を SSR 環境で使うときは、現在の生成方式に合わせてブラウザー側だけで描画してください。
このページでは `client:only="vue"` を使っています。
