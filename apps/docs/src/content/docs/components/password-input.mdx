PasswordInput は、パスワードの入力欄と「パスワードを表示」の切り替えボタンをひとつの枠にまとめた部品です。
[Field](/components/field/#先頭末尾の要素) の「先頭・末尾の要素」で紹介している Input + `suffix` の組み立てを部品にしたもので、
切り替え時のカーソル位置の復元、固定の読み上げ名と `aria-pressed`、Field との関連付けを内包します。
値は利用側が持ちます。

## プレビュー

入力欄の右のボタンで表示・非表示を切り替えます。切り替えてもカーソル位置と値は保たれ、フォーカスはボタンに残ります。

## 使い方

Field の中に置くと、Field の `id`・ラベル・説明・エラーを入力欄が受け取ります。

```tsx
// React
<Field id="password" label="パスワード" error={error}>
  <PasswordInput autocomplete="current-password" value={password} onValueChange={setPassword} />
</Field>

// Field の外では ariaLabel で名前を付ける
<PasswordInput ariaLabel="共有リンクのパスワード" value={password} onValueChange={setPassword} />
```

```vue
<!-- Vue -->
<Field id="password" label="パスワード" :error="error">
  <PasswordInput autocomplete="current-password" :value="password" :on-value-change="(next) => (password = next)" />
</Field>

<!-- Field の外では ariaLabel で名前を付ける -->
<PasswordInput aria-label="共有リンクのパスワード" :value="password" :on-value-change="(next) => (password = next)" />
```

表示状態を親で持つ場合は `visible` と `onVisibleChange` を渡します。省略すると内部で持ち、初期値は `defaultVisible` です。

## Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `id` | `string` | — | Field の中では Field の `id` を使う |
| `ariaLabel` | `string` | — | 読み上げ名。Field の外で使うときは必須 |
| `name` | `string` | — | フォーム送信時の名前 |
| `value` | `string` | — | 入力値。利用側が持つ |
| `placeholder` | `string` | — | 入力前の表示 |
| `autocomplete` | `string` | — | `'current-password'`（ログイン）か `'new-password'`（登録・変更）を推奨 |
| `disabled` | `boolean` | `false` | 入力欄と切り替えボタンを無効にする |
| `readOnly` | `boolean` | `false` | 入力欄を読み取り専用にする。表示の切り替えはできる |
| `onValueChange` | `(value: string) => void` | — | 入力のたびに呼ばれる |
| `visible` | `boolean` | — | 表示中か。省略すると内部で持つ |
| `defaultVisible` | `boolean` | `false` | 内部で持つときの初期値 |
| `onVisibleChange` | `(visible: boolean) => void` | — | 切り替えボタンの押下を通知する |
| `toggleLabel` | `string` | `'パスワードを表示'` | 切り替えボタンの読み上げ名。空白だけなら既定に戻る |

## キーボード操作

| キー | 動作 |
| --- | --- |
| Tab | 入力欄 → 切り替えボタンの順に移動する |
| Enter / Space（ボタン上） | 表示・非表示を切り替える。フォーカスはボタンに残る |

## アクセシビリティ

- 切り替えボタンの名前は「パスワードを表示」で固定し、状態は `aria-pressed`（`true` / `false`）で伝えます。
  名前と状態の両方を変えると「パスワードを隠す、押されていません」のように読み上げが分かりにくくなるためです。
- 切り替えでは入力欄の `type` を `password` と `text` で入れ替えます。要素は作り直さないので値は残ります。
  `type` を変えるとカーソル位置が失われるため、切り替える前に `selectionStart` / `selectionEnd` を控え、描画後に戻しています。
- フォーカスは切り替えボタンに留めます。続けて押せば元に戻せます。
- `id`・`aria-describedby`・`aria-invalid`・`required` は入力欄だけに付きます（Field から受け取ります）。
- フォーカス枠は入力欄にフォーカスがあるときだけ外側の枠に出ます。ボタンにフォーカスしたときはボタン自身の枠だけが出ます。
- アイコンは読み上げから外し、ボタンの名前だけを読ませます。
- パスワード管理ツールが正しく動くよう、`autocomplete` に `current-password` か `new-password` を渡してください。

## スタイル

- 枠・背景・ホバー・エラー・無効の見た目は Input と同じです（`Field/field.module.css` の共通 CSS を使います）。
- 切り替えボタンは Button のアイコンだけの `ghost` と同じ見た目で、高さと角丸は「外側の値 − 余白」で計算します。
  `--koyori-control-height-sm` や `--koyori-radius-md` を上書きしても枠からはみ出しません。
