ContextMenu は、行やカードを右クリックしたときに「編集」「削除」などの操作を出すメニューです。
表示位置と開閉はアプリ側で持ちます。1 つのメニューを複数の対象で使い回せます。

## プレビュー

行を右クリックするか、行にフォーカスして `Shift + F10`（またはメニューキー）を押すと開きます。
右端の三点ボタンからも同じメニューが開きます（スマホではこちらを使います）。

## 使い方

対象の `contextmenu` を受け、既定のメニューを止めて座標を保存します。座標は `contextMenuPosition` で取れます。

```tsx
// React
const [menu, setMenu] = useState({ open: false, x: 0, y: 0 });

<div tabIndex={0} onContextMenu={event => {
  event.preventDefault();
  setMenu({ open: true, ...contextMenuPosition(event) });
}}>請求書を送る</div>

<ContextMenu open={menu.open} x={menu.x} y={menu.y} label="タスクの操作"
  items={[
    { value: 'edit', label: '編集' },
    { value: 'delete', label: '削除する', destructive: true },
  ]}
  onSelect={run} onClose={() => setMenu(current => ({ ...current, open: false }))} />
```

```vue
<!-- Vue -->
<div tabindex="0" @contextmenu="openMenu">請求書を送る</div>
<ContextMenu :open="menu.open" :x="menu.x" :y="menu.y" label="タスクの操作" :items="items"
  :on-select="run" :on-close="() => menu.open = false" />
```

## 三点ボタンから開く

右クリックできない環境（スマホ、iOS の Safari など）のために、同じ ContextMenu を三点ボタンからも開きます。
`menuButtonPosition(event)` はボタンの左下の座標を返し、ボタンにフォーカスします（Escape などのあとにボタンへ戻すため）。

```tsx
// React
<Button ariaLabel="タスクの操作" variant="ghost" icon={<EllipsisIcon />}
  ariaHasPopup="menu" ariaExpanded={menu.open} ariaControls="task-menu"
  onClick={event => setMenu(menu.open ? { ...menu, open: false } : { open: true, ...menuButtonPosition(event) })} />
<ContextMenu id="task-menu" open={menu.open} x={menu.x} y={menu.y} … />
```

- ボタンの `ariaControls` と ContextMenu の `id` に同じ値を渡します。開いている間にボタンを押すと閉じます（外側クリックとしては扱いません）。
- 画面端で足りない場合は、右クリックと同じく左や上へ寄ります。サブメニューもそのまま使えます。
- 複数の行で 1 つのメニューを共用する場合は、開いた行のボタンだけ `ariaExpanded` を `true` にしてください。

## Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `open` | `boolean` | 必須 | 表示状態。アプリ側で管理する |
| `x` / `y` | `number` | 必須 | 画面内の座標。`contextMenuPosition(event)` の戻り値を渡す |
| `label` | `string` | 必須 | メニューの読み上げ名。例: 「タスクの操作」 |
| `id` | `string` | — | メニューの `id`。三点ボタンの `ariaControls` に同じ値を渡す |
| `items` | `ContextMenuItem[]` | 必須 | `{ value, label, disabled?, destructive?, items? }`。`items` で 1 階層だけサブメニューを持てる |
| `emptyMessage` | `string` | `項目がありません` | `items` が空のときに出す無効な項目 |
| `onSelect` | `(value: string) => void` | — | 項目を実行したときに先に呼ぶ。このときフォーカスは開く前の要素に戻っている |
| `onClose` | `() => void` | — | Escape・Tab・外側クリックと、`onSelect` の後に呼ぶ |

`destructive` は削除などの取り消せない操作に使います。色が変わりますが、色だけに頼らず
「削除する」のように結果が分かるラベルにしてください。

`onSelect` は `onClose` より先に呼ぶので、`onClose` で対象の情報を消しても `onSelect` では参照できます。
項目を実行するとフォーカスは開く前の要素に戻ってから `onSelect` が呼ばれるため、`onSelect` でダイアログを開くなどしてフォーカスを移せます。

## サブメニュー

項目に `items` を渡すと、その項目は実行されず、右側にサブメニューを開きます。階層は 1 段までです。

```tsx
items={[
  { value: 'edit', label: '編集' },
  { value: 'move', label: '移動', items: [
    { value: 'move-todo', label: '未着手' },
    { value: 'move-done', label: '完了' },
  ] },
]}
```

- `onSelect` には選んだ子の `value` だけが渡ります。**`value` はサブメニューも含めて重複しないようにしてください。**
- サブメニューを持つ項目には `›` が付きます。`destructive` は子の項目に付けてください。
- サブメニューは親メニューの右に出ます。右に入らなければ左へ反転し、下にはみ出す場合は上へずれます。
  画面より高い場合は高さを制限し、中をスクロールします。ルートのメニューは、右に入らなければ左へずれます。
- マウスを乗せてから少し待つと開き、別の項目へ移ると少し待ってから閉じます。

## キーボード操作

| キー | 動作 |
| --- | --- |
| `Shift + F10` / メニューキー | 対象にフォーカスしている状態で開く（対象に `tabindex="0"` が必要） |
| `↓` / `↑` | 項目を循環して移動する |
| `Home` / `End` | 先頭 / 末尾へ移動する |
| 文字キー | その文字で始まる項目へ移動する |
| `Enter` / `Space` | 実行して閉じる。サブメニューを持つ項目では開く |
| `→` | サブメニューを開き、先頭の項目へ移る |
| `←` | サブメニューを閉じて、親の項目へ戻る |
| `Escape` | サブメニューにいれば親の項目へ戻る。ルートでは閉じて、開く前の要素にフォーカスを戻す |
| `Tab` | 閉じて、開く前の位置から通常の移動を続ける |

開くと先頭の項目にフォーカスが移ります。無効な項目にもフォーカスは止まりますが、実行はできません。
すべての項目が無効な場合や 0 件の場合もメニューにフォーカスが入るので、Escape で閉じられます。外側をクリックしても閉じます。

## アクセシビリティ

- メニューは `role="menu"`、項目は `role="menuitem"` です。`label` が読み上げ名になります。
- **右クリックだけの操作にしないでください。** 三点ボタンからも同じ ContextMenu を開けるようにし、
  どちらからでも実行できるようにします。ContextMenu は近道として添えるものです。
- 対象に `tabindex="0"` を付けると、キーボードからも `Shift + F10` で開けます。
- iOS の Safari は長押しで `contextmenu` が発生しないため、右クリックの方法では開けません。三点ボタンを必ず置いてください。
- 無効な項目は `aria-disabled` を付け、実行できません。

## スタイル

Dropdown と同じ見た目・同じホバーの動きです。メニューの幅・余白・最大高さのトークンも共通です。
画面からはみ出す場合は、上下が反転し、左右は画面内に収まる位置へ寄ります。
