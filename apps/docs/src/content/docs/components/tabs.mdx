`Tabs` と `TabPanel` でリスト・ボードなどの表示を切り替えます。
選択値は利用側が `value` で渡し、`onValueChange` で変更要求を受け取ります。
URL 同期・永続化・データ取得は利用側で管理してください。

## Tabs

| 名前 | 型 | 説明 |
| --- | --- | --- |
| `id` | `string` | ページ内で一意な識別子。サーバーとクライアントで同じ値にする |
| `label` | `string` | `tablist` の読み上げ名。例: `タスクの表示形式` |
| `items` | `TabItem[]` | 順に並べるタブ |
| `value` | `string` | 外部で管理する選択値 |
| `onValueChange` | `(value: string) => void`（任意） | 別の有効なタブの選択要求。選択を受け入れる場合は `value` を更新する |
| `children` | React の要素 | 各タブに対応する `TabPanel`。Vue は default slot |

`TabItem` は `value: string`・`label: string`・`disabled?: boolean` です。
`value` は一覧内で一意で安定した値、`label` は空でない表示名にします。
各項目に同じ `value` の `TabPanel` を一つずつ置いてください。
`TabsProps`・`TabItem`・`TabPanelProps` は Vue・React の公開エントリーから import できます。
Vue の変更通知は `:on-value-change="handler"` で渡します。

既に選択されているタブの操作・矢印での移動・外部からの `value` 変更では通知しません。
利用側が変更要求を受け入れなければ、元の選択とパネルを維持します。
`value` が存在しないか無効な場合は、最初の有効な項目を表示し、値の補正通知は行いません。
有効な項目がなければ選択も表示パネルもなくなり、空の `items` ではタブ一覧も隠します。

## TabPanel と非表示の扱い

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `value` | `string` | 必須 | 親の `items` にある値 |
| `tabIndex` | `0 \| -1` | `0` | 最初の内容が入力欄などフォーカス可能な要素なら `-1` にする |
| `children` | React の要素 | — | パネルの内容。Vue は default slot |

選択されていないパネルには HTML の `hidden` を付けます。DOM と入力状態を保ちつつ、
表示・Tab 移動・アクセシビリティツリーから除外します。非表示でも内部の処理や通信は停止しません。
フォーム送信から入力値を除外する属性でもないため、送信対象や検証対象は利用側で管理してください。
読み込み中やエラーの表示もパネル内に置けます。パネルを遅延作成する場合も、関連付け先の `TabPanel` は残してください。

外部変更でパネル内のフォーカスが隠れる場合は、新しい選択タブへ移します。
フォーカス中のタブが削除・無効化された場合も、有効なタブが残っていれば選択タブへ移します。
外部のボタンや別のタブにあるフォーカスは移しません。
項目を全削除・全無効化する場合は、利用側で次の操作先へフォーカスを移してください。

## キーボードと読み上げ

横向き・手動選択のタブです。選択とフォーカスを分け、フォーカスだけの移動ではパネルを切り替えません。

| キー | 動作 |
| --- | --- |
| 外から `Tab` / `Shift + Tab` | 選択中のタブへ入る |
| `←` / `→` | 前後の有効なタブへ移動。端で循環し、無効なタブを飛ばす。RTL では左右を反転 |
| `Home` / `End` | 最初・最後の有効なタブへ移動 |
| `Enter` / `Space` | フォーカス中のタブを選択するよう通知 |
| タブで `Tab` | 一覧を出て、表示パネルまたは先頭の操作要素へ移動 |
| `↑` / `↓` | ブラウザー標準のスクロールを保つ |

`tab` の `aria-controls` と `tabpanel` の `aria-labelledby` を、`id` と項目の値から生成した ID で接続します。
`aria-selected`、背景色、下線で選択を示し、キーボードのフォーカス枠と区別します。
無効なタブはネイティブの `disabled` で操作・フォーカスを止めます。
幅が足りない場合はタブ一覧だけ横スクロールし、キーボードで移動したタブをブラウザーが表示範囲に入れます。
ホバーは共通ハイライトを使い、動きを減らす設定ではアニメーションを停止します。

[W3C APG の Tabs パターン](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)と
[デジタル庁のアクセシビリティガイド](https://www.digital.go.jp/resources/introduction-to-web-accessibility-guidebook)を参照しています。
Storybook に外部変更、変更の拒否、無効・空・単一項目、狭い幅、RTL、複数配置の例があります。
ビルド後に `node scripts/check-tabs.cjs` で両環境のキーボード操作・状態保持・axe 検査を実行できます。
