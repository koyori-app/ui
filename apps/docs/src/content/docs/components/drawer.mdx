Drawer は、画面の上・下・左・右のいずれかの端から滑り出るモーダルです。
常時表示・畳み込み・アイコンだけの表示は中身の [Sidebar](../sidebar/) の役目で、Drawer は覆う役目だけを持ちます。
Sidebar を入れて、ハンバーガーボタンで開閉するナビゲーションに使います。

Dialog と同じくネイティブの `dialog` 要素を使い、フォーカスの閉じ込め・背景の操作停止・Escape での終了・
閉じたあとのフォーカス復帰をブラウザーに任せています。

## 使い方

表示状態はアプリ側で持ちます。`open` に渡し、`onClose` で false に戻してください。
開くボタンと閉じるボタンはアプリ側に置きます。

```tsx
// React
const [open, setOpen] = useState(false);

<Button ariaLabel="メニューを開く" variant="ghost" icon={<MenuIcon />} onClick={() => setOpen(true)} />
<Drawer open={open} label="メニュー" placement="left" onClose={() => setOpen(false)}>
  <Sidebar label="メインナビゲーション"
    header={<Button ariaLabel="メニューを閉じる" variant="ghost" icon={<XIcon />} onClick={() => setOpen(false)} />}>
    <SidebarLink label="概要" href="/overview" current />
  </Sidebar>
</Drawer>
```

```vue
<!-- Vue -->
<Button ariaLabel="メニューを開く" variant="ghost" :on-click="() => open = true">
  <template #icon><MenuIcon /></template>
</Button>
<Drawer :open="open" label="メニュー" placement="left" :on-close="() => open = false">
  <Sidebar label="メインナビゲーション">
    <template #header>
      <Button ariaLabel="メニューを閉じる" variant="ghost" :on-click="() => open = false"><template #icon><XIcon /></template></Button>
    </template>
    <SidebarLink label="概要" href="/overview" current />
  </Sidebar>
</Drawer>
```

## Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `open` | `boolean` | 必須 | 表示状態。アプリ側で管理する |
| `label` | `string` | 必須 | Drawer の名前として読み上げる |
| `placement` | `'left' \| 'right' \| 'top' \| 'bottom'` | `'left'` | 滑り出る画面端 |
| `modal` | `boolean` | `true` | `false` にすると `dialog` を使わず、中身をその場所に描く。広い画面で常時表示にするときに使う |
| `onClose` | `() => void` | — | Escape・背景クリックで呼ぶ |
| 子要素 | — | — | 中身。Drawer いっぱいに広がる。Vue は既定スロット |

## キーボード操作

| キー | 動作 |
| --- | --- |
| `Tab` / `Shift + Tab` | Drawer 内だけを移動する。背景の要素には移らない |
| `Escape` | 閉じて `onClose` を呼ぶ。中でメニューが開いていれば、そのメニューだけが閉じる |
| `Enter` / `Space` | フォーカス中のリンクやボタンを実行する |

背景をクリックしても閉じます。開いている間は背景をスクロールできません。

## アクセシビリティ

- 開くと最初のフォーカス可能な要素にフォーカスが移り、閉じると開く前のボタンに戻ります。
- 開くボタンがアイコンだけのときは、`ariaLabel` に「メニューを開く」のように読んで分かる名前を付けます。
- 開いている間は背景が操作できなくなるため、開くボタンに `aria-expanded` は付けません。
- 閉じるボタンは持ちません。Escape と背景クリックに加え、`XIcon` と `ariaLabel` を使った閉じるボタンを中に置いてください。

## スタイル

- 画面端に付き、画面の内側に向いた角だけが丸くなります。端側には枠線を引きません。
- 左右の幅は `--koyori-drawer-width`（280px）、上下の高さは `--koyori-drawer-height`（60vh）です。
- 中の Sidebar は枠と角丸を外し、幅を Drawer いっぱいに広げます（`--koyori-sidebar-border`・`--koyori-sidebar-radius`・`--koyori-sidebar-width`）。
- 画面幅で出し分ける組み方は [レスポンシブなナビゲーション](../../blocks/responsive-navigation/) にあります。
- 中の Sidebar に `rail` を渡すと、Drawer の幅も `--koyori-sidebar-rail-width`（64px）に縮みます。左右に出すときに使えます。
- 開閉とも弾まないスライドで動き、「動きを減らす」設定では止まります。閉じるときの動きは `transition-behavior: allow-discrete` に対応したブラウザーだけで、非対応のブラウザーではすぐに消えます。
