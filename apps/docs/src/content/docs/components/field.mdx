Field は、ラベル・説明・エラーを中の Input・Textarea・Picker に関連付けます。
Input は1行の文字・数値入力、Textarea は複数行の文字入力です。

## プレビュー

タイトルを空のまま「タスクを作成」を押すと、エラーを表示してタイトルへフォーカスを戻します。

<FieldPreview />

## 使い方

Field の中に Input・Textarea・Picker のいずれかを1つだけ置きます。Field の `id` が入力欄に付き、ラベルの `for` と説明・エラーの関連付けに使われます。
`id` はページ内で一意にしてください。

入力値は `value` で渡し、変更は `onValueChange(value)`（Vue: `:on-value-change`）で受け取ります。
入力のたびに呼ばれます。

## Field の Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `id` | `string` | 必須 | 中の入力欄に付ける id |
| `label` | `string` | 必須 | 入力欄のラベル |
| `description` | `string` | — | ラベルの下に表示する補足 |
| `error` | `string` | — | 入力欄の下に表示するエラー。指定すると入力欄を無効な値として伝える |
| `requiredText` | `string` | `必須` | 必須表示の文言 |
| `required` | `boolean` | `false` | 入力を必須にし、ラベルに「必須」を表示する |

## Input・Textarea の Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `value` | `string` | — | 入力値 |
| `onValueChange` | `(value: string) => void` | — | 入力のたびに呼ぶ関数 |
| `name` | `string` | — | フォーム送信時の名前 |
| `placeholder` | `string` | — | 入力例。ラベルの代わりには使わない |
| `disabled` | `boolean` | `false` | 操作を無効にする |
| `readOnly` | `boolean` | `false` | 読み取り専用にする |
| `ariaLabel` | `string` | — | Field の外で使うときの名前（`aria-label`） |
| `id` | `string` | — | Field の外で使うときの id。Field の中では Field の `id` を使う |
| `type` | `'text' \| 'email' \| 'password' \| 'search' \| 'tel' \| 'url' \| 'number'` | `'text'` | Input のみ。入力の種類 |
| `min` / `max` | `number` | — | Input の `type="number"` のみ。数値の下限・上限 |
| `step` | `number \| 'any'` | `1`（ブラウザー既定） | 数値の刻み。正数を指定。`'any'` は刻みの検証をしない |
| `onNumberCommit` | `(value: number \| null) => void` | — | 数値入力の確定通知。有効な空欄は `null`、0は `0` |
| `onNumberInvalid` | `(message: string) => void` | — | 数値の確定を拒否したとき、ブラウザーの検証メッセージを通知 |
| `autocomplete` | `string` | — | Input のみ。自動入力の種類。例: `email`、`name` |
| `rows` | `number` | `3` | Textarea のみ。表示する行数 |
| `prefix` / `suffix` | React: 要素 / Vue: 同名スロット | — | Input のみ。入力欄の前後に置く要素。下の「先頭・末尾の要素」を参照 |

## 数値入力

既存の Input に `type="number"` を指定します。ラベル・共通スタイルと文字列の変更通知を再利用できるため、別の NumberInput は追加していません。
用途の制約は利用側で渡します。進捗率なら `min={0}`・`max={100}`・`step={1}`、見積時間なら `min={0}`・`step={0.25}` などです。刻みの起点は `min`、未指定なら0です。現在のdraftでは起点を変えません。

<NumberInputPreview />

`value` と `onValueChange` は数値入力でも **文字列** です。空欄は `''`、0は `'0'` として保持し、入力のたびに通知します。入力途中で `Number(text)` に変換すると空欄まで0になるため、draftと確定値を分けて管理します。

通知と検証の契約は次のとおりです。

- `onNumberCommit` は blur または変換中でない Enter で呼びます。Enter直後のblur・Enter連打は、新たに編集するまで同じ確定を通知しません。再フォーカスすると新しい編集として扱います。
- 空欄は `null`、有効な数値は `valueAsNumber` の値です。`Field required` の空欄は確定できません。
- 入力途中の `-` や `1e` は、ブラウザーの `input.value` では `''` になることがあります。`onValueChange` は画面内の未完成文字列を完全には保持しません。確定時には `validity.badInput` も含むネイティブ検証を行うため、未完成の入力を空欄の `null` として確定しません。受け付ける文字、指数表記、ロケールの小数点はブラウザーに従います。
- 範囲外・step不一致・未完成・必須の空欄では `onNumberCommit` を呼ばず、`onNumberInvalid` に `validationMessage` を渡します。入力を丸めたり上限・下限へ補正したりしません。エラーは上の例のように `Field error` に表示してください。編集・再確定が成功したときのエラー解除は利用側が行います。
- `disabled` / `readOnly` では変更・確定・エラー通知を行いません。外側からの `value` 更新も変更・確定通知を発生させません。数値用の属性と通知は他の `type` に影響しません。

`onNumberCommit` は入力欄の値の通知であり、保存処理ではありません。InlineEdit と組み合わせる場合、Input の blur 通知を永続化に直結せず、draftの更新に使ってください。保存・取消とその順序は InlineEdit の `onCommit` / `onCancel` と利用側で管理します。ボタン確定などで最新値が必要なら対象の `HTMLInputElement.validity.valid` を確認し、空欄なら `null`、それ以外は `valueAsNumber` を読みます。古い確定値だけを見て保存しないでください。

ネイティブの数値入力は spinbutton として公開され、上下矢印で値を増減できます。Tabで移動し、通常の文字編集キーはブラウザーに任せます。Home/Endなどの挙動もブラウザー標準です。
設計の参照は [APG Spinbutton](https://www.w3.org/WAI/ARIA/apg/patterns/spinbutton/) と[デジタル庁の導入ガイドブック](https://www.digital.go.jp/resources/introduction-to-web-accessibility-guidebook)です。

## 先頭・末尾の要素

Input には `prefix`（React は要素、Vue は同名スロット）と `suffix` を渡せます。
単位や通貨記号のような文字のほか、パスワードの表示切り替えのようなボタンも置けます。
入力欄と前後の要素はひとつの枠に収まり、枠・背景・ホバー・エラー・無効の見た目は外側の要素が描きます。

<PasswordInputPreview />

```tsx
// React
<Field id="password" label="パスワード">
  <Input type={visible ? 'text' : 'password'} value={value} onValueChange={setValue}
    suffix={<Button variant="ghost" ariaLabel="パスワードを表示" ariaPressed={visible ? 'true' : 'false'}
      icon={visible ? <EyeOffIcon /> : <EyeIcon />} onClick={toggle} />} />
</Field>
```

```vue
<!-- Vue -->
<Field id="password" label="パスワード">
  <Input :type="visible ? 'text' : 'password'" :value="value" :on-value-change="(next) => (value = next)">
    <template #suffix>
      <Button variant="ghost" aria-label="パスワードを表示" :aria-pressed="visible ? 'true' : 'false'" :on-click="toggle">
        <template #icon><EyeOffIcon v-if="visible" /><EyeIcon v-else /></template>
      </Button>
    </template>
  </Input>
</Field>
```

`id`・`aria-describedby`・`aria-invalid` は入力欄だけに付きます。Tab は入力欄のあと末尾のボタンへ進みます。
フォーカス枠は入力欄にフォーカスがあるときだけ外側の枠に出ます（`focus-within` ではなく `:has()` で入力欄だけを見ています）。
末尾のボタンにフォーカスしたときはボタン自身の枠だけが出るので、枠が二重になりません。

パスワードの表示切り替えでは、`type` を `password` と `text` で入れ替えます。値は利用側が持つため消えませんが、
カーソル位置は切り替えで失われます。上の例のように `selectionStart` / `selectionEnd` を控えて、描画後に `setSelectionRange` で戻してください。
ボタンの名前は「パスワードを表示」で固定し、状態は `ariaPressed` で伝えます（名前と状態の両方を変えると読み上げが分かりにくくなります）。

前後の要素の高さと角丸は「外側の値 − 余白」で計算するので、`--koyori-control-height-sm` や `--koyori-radius-md` を上書きしても枠からはみ出しません。
文字だけを置く場合は読み上げから除かれません。単位を読み上げたくない場合は `aria-hidden="true"` を付けた要素を渡してください。

## アクセシビリティ

- ラベルは `label` 要素で入力欄に関連付けます。ラベルを押すと入力欄にフォーカスが移ります。
- 説明とエラーは `aria-describedby` で入力欄に関連付け、エラーがあるときは `aria-invalid="true"` を付けます。
- 常設の `aria-live="polite"` 領域で後から出たエラーを通知します。
- Picker の必須状態は一覧の `aria-required` と、トリガーの名前に含めた `requiredText` で伝えます。説明・エラーはトリガーだけに関連付けます。選択値の必須チェックとフォーム送信はアプリ側で行います。
- エラーは枠線の色だけでなく、文章でも伝えます。何が誤りで、どう直せばよいかを書いてください。
- 送信時にエラーがあれば、最初のエラーの入力欄にフォーカスを移してください。プレビューの例もそうしています。
- Input・Textarea の `required` はネイティブの `required` 属性を付けます。ブラウザーの検証メッセージを使わない場合は、`form` に `novalidate` を付けます。
- 「必須」の表示は読み上げから除き、入力欄の必須状態として伝えます。
- 名前やメールアドレスなど利用者自身の情報を入力する欄には、`autocomplete` を指定してください。
- Field の外で使う場合は、`ariaLabel` などで必ず名前を付けてください。
- Input の `prefix` / `suffix` に置いたボタンは入力欄の外にあります。名前を付け、Tab で順に到達できるようにしてください。

## スタイル

入力欄の枠線は `--koyori-color-border-strong`、エラーの文字と枠線は `--koyori-color-danger` を使います。
変更するときも、枠線は背景とのコントラスト比 3:1、エラーの文字は 4.5:1 以上を保ってください。
