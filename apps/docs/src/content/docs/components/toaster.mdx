Toaster は、保存の完了など操作の結果を画面の右下に一時的に出します。数秒で自動的に消えます。
その場に残して伝えたい失敗や注意は [Alert](/components/alert/) を使ってください。

## プレビュー

「保存」「作成」「失敗」を押すと、右下にトーストが出ます。マウスを載せるかフォーカスを入れると消えるのが止まります。

## 使い方

アプリのルートに `<Toaster />` を 1 つだけ置き、どこからでも `toast` を呼びます。

```tsx
// React
<Toaster />

toast.success('保存しました。');
toast.success('タスクを作成しました。', { action: { label: 'タスクを開く', href: `/tasks/${id}` } });
toast.info('項目を削除しました。', { action: { label: '元に戻す', onClick: undo } });
```

```vue
<!-- Vue -->
<Toaster />

<script setup>
toast.error('保存できませんでした。時間をおいて試してください。');
</script>
```

## API

`toast.success` / `toast.error` / `toast.info` は本文と任意の `options` を受け取り、トーストの番号を返します。

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `options.action` | `{ label, href?, onClick? }` | — | 本文の後ろに置く操作を 1 つ。`href` があればリンク、なければボタン。押すとトーストは閉じる |
| `options.duration` | `number` | `5000`（`action` 付きは `8000`） | 自動で消えるまでの ms。`0` は手動で閉じるまで残す |
| `toast.dismiss(id?)` | `(id?: number) => void` | — | 番号を渡すとその 1 件、省略すると全部閉じる |

`Toaster` の Props です。

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `limit` | `number` | `3` | 同時に表示する上限。超えたら古いものから消す |
| `label` | `string` | `'通知'` | 表示領域の読み上げ名 |
| `dismissLabel` | `string` | `'閉じる'` | 閉じるボタンの読み上げ名 |

- ストアはアプリで 1 つです。`Toaster` も 1 つだけ置いてください（`limit` もそこで決まります）。
- サーバーでは `toast` を呼ばないでください。表示されないまま、`duration: 0` のものが残ります。
- 退場の動きはありません。消えるときはすぐに取り除かれます。

## アクセシビリティ

- `success`・`info` は `role="status"`、`error` は `role="alert"` です。ライブ領域には接頭辞（完了・エラー・お知らせ）と本文だけを入れ、
  操作と閉じるボタンは外に置いています。同じ内容を別のライブ領域に重ねないでください。二重に読まれます。
- 出てもフォーカスは奪いません。キーボードでは Tab でトーストのボタンやリンクへ移れます。
- ホバーやフォーカスが領域の中にある間は、すべてのトーストの自動消去を止めます。外れると残り時間から再開します。
- 読み上げで追いやすいよう、操作は 1 つまでです。長く読ませる内容や、必ず対応が要る内容はトーストにしないでください。
- 閉じたトーストにフォーカスがあると、フォーカスは `body` に戻ります。操作の起点へ戻したい場合は利用側で移してください。
- 「動きを減らす」設定では入場の動きを止めます。強制配色では接頭辞が本文と同じ色になり、言葉だけが残ります。
- モーダルの Dialog が開いている間も、top layer に出るため見えて読めます。ただしモーダル外は操作できないため、トースト内のボタンは押せません。

## スタイル

- 幅は `--koyori-toast-width`（既定 `360px`）、位置は右下です（`inset-inline-end` のため、右から左へ書く言語では左下）。
  画面が狭いときは幅を `100%` から左右の余白を引いた値に収めます。
- 種類ごとの色は Alert と同じ共通トークンです。個別に変える場合は、Toaster を囲む要素で `--toast-color`（文字・枠線）と
  `--toast-background`（背景）を上書きします。上書きするときも、本文と背景は 4.5:1 以上を保ってください。
- 操作がリンクのときは下線を付けて、ボタン（Button の `tertiary`）と見分けられるようにしています。
