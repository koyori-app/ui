Avatar は利用者を表す円形の画像です。画像がない場合や読み込みに失敗した場合は、名前のイニシャルを表示します。
AvatarGroup は複数人を少し重ねて並べ、表示しきれない人数を `+N` にまとめます。

## プレビュー

スライダーで表示する最大人数を変えると、あふれた人数が `+N` にまとまります。

## Avatar の Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `name` | `string` | 必須 | 表示名。画像の代替テキストとイニシャルに使う |
| `src` | `string` | — | 画像の URL。省略・読み込み失敗時はイニシャルを表示する |
| `size` | `number` | `32` | 円の直径（px） |

イニシャルは、空白で区切られた語の先頭を2つまで使います。
「山田 太郎」は「山太」、区切りのない「山田太郎」は「山」、「yupix」は「y」です。

## AvatarGroup の Props

| 名前 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `label` | `string` | 必須 | グループの目的。`aria-label` として読み上げる |
| `items` | `{ name: string; src?: string }[]` | 必須 | 並べる人。順番どおりに表示する |
| `max` | `number` | — | 表示する最大人数。超えた分は `+N` にまとめる |
| `size` | `number` | `32` | 円の直径（px） |
| `formatOverflow` | `(count: number) => string` | `他 N 人` | `+N` の読み上げ文 |

## アクセシビリティ

- 画像には `name` を代替テキストとして付けます。イニシャルの表示も、読み上げでは `name` になります。
- 名前がすぐ隣に文字で見えている場合は、同じ名前を2回読み上げることになります。
- グループは `role="group"` と `label` で、まとまりとその目的を伝えます。
- `+N` は「他 N 人」と読み上げます。文言は `formatOverflow` で変更できます。
- 誰かを選ぶ操作には、Avatar 自体ではなくボタンやリンクを使ってください。Avatar は表示だけを行います。

## スタイル

重なりは 8px、隣との境界は背景色（`--koyori-color-surface`）の縁取りで作ります。
背景の異なる場所に置く場合は、`--koyori-color-surface` をその背景色に合わせてください。
